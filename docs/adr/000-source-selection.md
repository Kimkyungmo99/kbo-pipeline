# ADR 000 — 데이터 소스: 네이버 스포츠 비공식 게이트웨이

날짜: 2026-08-19 · 상태: 채택

**결정**: 투구 단위 데이터 소스로 네이버 스포츠 비공식 API(`api-gw.sports.naver.com`)를 사용한다.

**이유**: (1) 투구 단위 이벤트(구종·구속·결과·볼카운트·주루·점수)가 존재하는 유일하게 확인된 무료 소스, (2) 인증·쿠키 불필요, User-Agent만으로 접근 가능, (3) 종료 경기는 이닝별 정적 JSON이라 재현 가능한 수집이 성립, (4) 경기 목록 API가 gameId와 경기 상태(RESULT/취소)를 함께 제공해 수집 대상 판별이 한 번에 됨.

**대안과 기각 사유**: KBO 공식 기록실 HTML은 경기·타석 단위 집계 위주로 투구 단위가 없다. 공개 크롤러(kbodata 등)도 경기 단위 집계에 그친다.

**리스크**: 비공식 API라 스키마가 예고 없이 바뀔 수 있다 → raw JSON 원본 보존(재파싱 가능), 응답 구조 샘플을 `docs/source-schema/`에 기준선으로 유지, URL은 `config/sources.yaml`로 분리.

**검증으로 확인된 특성**: 취소 경기는 relay가 null(RESULT 필터 필수). `currentGameState`는 투구 직후 상태(삼진 순간 strike=3, 볼넷 순간 ball=4) — "투구 직전 상태"로의 변환은 변환 레이어(dbt staging)에서 shift로 처리한다.
