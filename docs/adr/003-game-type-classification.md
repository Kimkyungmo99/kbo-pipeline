# ADR 003 — 경기 종류는 gameId 접두로 분류한다: 포스트시즌 수집, 올스타 제외

날짜: 2026-09-11 · 상태: 채택

## 배경

수집 대상 규칙은 처음에 `categoryId == "kbo" AND statusCode == "RESULT"` 둘이었다. 7월 백필에서 **올스타전**(`99990706WEEA02024`)이 이 둘을 통과해 정규시즌 데이터에 섞였다. 이벤트전은 규칙이 달라 지표의 오염원이다.

1차 수정으로 "gameId 앞 8자리 = 경기 날짜"를 세 번째 조건으로 넣었다. 그런데 10월을 돌리기 전에 목록 API를 덤프해보니(`probe_list.py`) 이 규칙이 **포스트시즌과 순위결정전까지 전부 걸러내고 있었다**. 문서에는 반대로 "통과시킨다"고 적혀 있었다 — 실측 없이 쓴 판단이었다.

## 실측: gameId 앞 4자리는 연도가 아니라 경기 종류 코드다

MMDD·팀코드·경기번호·시즌은 그대로이고 앞 4자리만 바뀐다. 2024 시즌 전 종류를 실측했다.

| 접두 | 종류 | 실측 gameId |
|---|---|---|
| 날짜(YYYY) | regular | `20240928HTLT02024` |
| 3333 | semi_po (준플레이오프) | `33331005KTLG02024` |
| 4444 | wildcard | `44441002KTOB02024` |
| 5555 | po (플레이오프) | `55551013LGSS02024` |
| 6666 | tiebreaker (순위 결정전) | `66661001SKKT02024` |
| 7777 | ks (한국시리즈) | `77771022SSHT02024` |
| 9999 | allstar | `99990706WEEA02024` |

라운드 순서와 숫자는 일치하지 않는다(WC 4444 < 준PO 3333 < PO 5555). 추측으로 채웠다면 틀렸을 것이다.

## 결정

1. `ingestion/gametype.py`에 **순수 함수** `classify_game_type(game_id)`를 둔다. 접두 사전에 있으면 그 종류, 앞 8자리가 날짜이고 **연도가 시즌 끝 4자리와 같으면** regular, 그 외 unknown. (연도 일치 조건이 없으면 `8888…` 같은 미등록 코드가 날짜로 파싱돼 regular로 샌다 — 테스트가 잡았다.)
2. bronze에 `game_type` 컬럼을 둔다. gameId만으로 결정되므로 **raw 재파싱만으로 소급·재생산**된다 (목록 API 응답을 따로 보존할 필요가 없어졌다).
3. 수집 대상 = kbo AND RESULT AND `game_type ∈ {regular, tiebreaker, wildcard, semi_po, po, ks}`. 올스타·unknown 제외. 정규는 "gameId 날짜 = 목록 날짜"를 추가로 요구한다.
4. **미확인 접두는 조용히 빠지지 않는다**: `report_skipped`가 kbo·RESULT인데 제외된 경기를 종류와 함께 출력하고, unknown이면 경고한다. 새 시즌에 새 코드가 등장하면 여기서 드러나고, 실측 후 사전에 등록한다.
5. 순위결정전(tiebreaker)이 정규시즌 기록에 포함되는지는 이 레이어에서 정하지 않는다 — 별도 라벨로 두고 dbt에서 결정한다. "포스트시즌은 따로 기록한다"는 결정의 실체가 이 라벨이다.

## 알려진 경계 케이스

- **서스펜디드 게임**: 2024 KS 1차전(10/21 중단 → 10/23 재개·종료). 목록 API는 완료일에 싣고 gameId의 MMDD는 편성일을 유지한다. bronze `dt`는 목록(완료일) 기준이라 10/23 파티션에 `77771021`·`77771023`이 함께 있다 — 정합. 정규시즌에는 서스펜디드 제도가 없어 3번의 날짜 일치 조건과 충돌하지 않지만, 생기면 `report_skipped`가 "제외: … (regular)"로 드러낸다.
- `20241002BL1` 같은 `kbaseballetc` 항목은 categoryId 조건이 막는다. 분류 함수는 이를 unknown으로 본다(형식 자체가 다름).

## 결과

2024 시즌 730경기: regular 713 / tiebreaker 1 / wildcard 2 / semi_po 5 / po 4 / ks 5. 포스트시즌 18경기의 전이 검증 신규 위반 0건.

## 교훈

- 소스의 식별자 체계를 먼저 읽으면 설계가 단순해진다. 목록 응답 보존·별도 매핑 테이블 없이 gameId 한 줄로 끝났다.
- 같은 날 "확인해보니 반대였다"가 두 번 있었다(날짜 규칙의 효과, 7777의 정체). 둘 다 실측이 잡았다. 접두처럼 규칙성이 보이는 값일수록 추측이 아니라 덤프로 확정한다.
